--- VISORA background (v1) ---

This project was my first AI system project, developed in 2025 during my second semester. The main idea was to combine an AI speech assistant with object detection to create an assistive AI system for visually impaired users.

At the time, I had no prior knowledge of how AI systems worked, nor did I have a strong understanding of application development, including frontend and backend fundamentals. My programming background was mainly limited to SQL, C, and beginner-level Python, which was far from sufficient for building a computer vision and speech-based AI system.

In the early stage, because of things I learned from my Algorithm and Programming class, I used files to store information shared between Python programs. Then, I realized how inefficient this approach was, so I switched to using function returns. Even though it may seem simple, I was very proud to be able to build VISORA v1.

--- VISORA v2 (real-time approach) ---

Then, in my third semester, my professor gave me the same project, so I decided to continue developing VISORA v2. My professor also told me to make it real-time, so I did. I also changed the model because I already had a better understanding of deep learning, so I used a pretrained YOLOv8 object detection model trained on the COCO dataset. I will provide a reason why this was a good approach.

I have not continued this project since I discovered a major limitation: dataset availability and computational cost. However, as time passed, I gained knowledge on how to train models on larger datasets efficiently using cloud computing. I will also create a Medium article documenting this process. v3 in PROGRESS!!
